# Tailwind v4 Styling Skill

## 1. Core Principles
- **Utility-First**: Avoid custom CSS. Use baked-in Tailwind utilities.
- **Theme Usage**: Use the project's design tokens (colors, spacing, typography) from the config.
- **Responsive Design**: Always use mobile-first breakpoints (`sm`, `md`, `lg`, etc.).

## 2. Advanced Features
- Use Tailwind v4's optimized build and potential `@theme` syntax if applicable.
- Leverage `tailwind-merge` and `clsx` for dynamic class grouping.

## 3. Aesthetics
- Prioritize premium looks: subtle shadows, glassmorphism, smooth transitions, and high-quality color palettes.
